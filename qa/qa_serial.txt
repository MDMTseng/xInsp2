# qa_serial.txt — tests that MUST run serially (never in the parallel pool).
#
# run_qa.py runs the parallel-safe qa_* concurrently (--jobs), THEN runs the
# tests listed here one at a time with nothing else running. These assert on
# TIMING / CONCURRENCY-COUNT / LOAD behaviour — a backend is itself multi-threaded
# (dispatch workers + OpenMP + a runtime cl.exe compile), so N in parallel
# oversubscribes the CPU and starves these of the determinism their assertions
# need. (This is NOT a data-isolation issue — ports come from free_port() and
# J1's per-PID work_dir removed the shared-build-dir collision; it is purely CPU
# oversubscription breaking timing assertions.)
#
# Conservative on purpose: a wrongly-serial test only costs wall-time; a wrongly-
# parallel timing test flakes. Add here if a parallelised test starts flaking.
# Format: one folder name per line; # comments allowed.

# --- known load-sensitive (already flaky-quarantined for exactly this reason) ---
qa_reentrancy
qa_cpu_affinity
qa_lifecycle_teardown

# --- queue / back-pressure timing (assert first_gap, max_inflight, ratios) ---
qa_slow_consumer
qa_semaphore_queue
qa_plugin_queue_sim
qa_overflow_block

# --- live-UI egress: asserts the DELIVERED frame RATE (egress fps vs a fast
#     source) + pushes>>delivered collapse — wall-clock rate assertions flake
#     under CPU oversubscription. ---
qa_ui_egress

# --- dispatch / group parallelism + interval timing ---
qa_dispatch_groups

qa_watchdog

# --- capability-provider e2e: loads + certifies a lib-plugin DLL and drives cap

#     and every cap call returns rc=-99 (empirically flaked here at jobs=4). ---
qa_cap_imgcodec
qa_cap_imgcodec_autoload

# --- added 2026-07-22 after flaking at --jobs=2 on a 4-core aarch64 host ---
#     Two have a confirmed mechanism; the third is here on this file's own
#     conservative rule (it flaked in parallel, and being wrongly-serial only
#     costs wall-time).
#

#       entry above.
#     qa_param_state_isolation: observed failing in a full --jobs=2 run, but NOT
#       reproduced when run 3-way concurrent by hand, so the mechanism is
#       unconfirmed. Listed rather than argued about.
qa_func
qa_jpeg_preview
