# Historically the wave-1 GO/NO-GO bench (docs/new_gen/08 §1d): Pack (v3) vs
# Record (v2 shared doc) — the Record lanes (frame_micro_record_roundtrip_ns,
# frame_hotpath_record_p50_us_320x240x3_p1) were retired at THE CUT. The
# gated metrics the bench emits now are:
#   frame_micro_framebuilder_ns              v3 PackBuilder+seal+read+drop (slab
#                                            build + raw reads + one-shot free)
#   frame_micro_slab_read_ns                 v3 M typed raw-slab reads on one
#                                            sealed pack (binary search + raw
#                                            load, no msgpack decode)
#   frame_hotpath_frame_p50_us_320x240x3_p1  v3 closed-loop single-worker p50
#                                            (event carries a sealed Pack by
#                                            MOVE; consumer reads raw slab)
#
# SLAB MIGRATION (packv3, 2026-07-14): frame_micro_slab_read_ns REPLACES the
# retired frame_micro_plane_memcpy_hop_ns ("mp plane + memcpy-hop +
# offset-read") — that lane measured the pre-slab representation (a contiguous
# canonical-msgpack small plane hopped by memcpy, fields decoded at precomputed
# offsets), which nothing in production does anymore. Pre-migration numbers for
# frame_micro_framebuilder_ns and the hotpath p50 are also NOT comparable:
# scalars now store RAW in one slab (no msgpack encode on build, no decode on
# read). Recapture from scratch on the gating machine.
